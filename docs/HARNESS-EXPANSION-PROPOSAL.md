# Harness Expansion — Moved to Agent Ecosystem Roadmap

The roadmap now targets **all autonomous AI agents**, not only coding-agent
harnesses. Its canonical location is:

**[Agent Ecosystem Integration Roadmap](AGENT-ECOSYSTEM-ROADMAP.md)**

The new plan covers framework-built agents; enterprise and customer-facing
workflows; financial, browser, research, infrastructure, multi-agent and coding
systems; and longer-term embodied/robotics research. It defines separate,
verifiable **observe, evaluate, authorize, and effect/recovery evidence** levels.

The former coding-harness analysis is preserved in the dedicated
**Coding-agent harness track** section of the new document. It remains a proposal:
the roadmap does not add integrations or imply support for unimplemented hosts.
