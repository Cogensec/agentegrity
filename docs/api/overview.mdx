## Entry points

| Name | Purpose |
|---|---|
| `init(...)` | Detect frameworks, build adapters. [Client & runtime](/docs/api/client-runtime) |
| `shutdown()` | End sessions, flush exporters |
| `detect_frameworks()` | Adapter names whose framework is importable |
| `AgentegrityRuntime` | Handle returned by `init()` |
| `AgentegrityClient` | High-level client |

## Prefixed framework re-exports

Every framework entry point is also available from the top level under a prefixed name, so
you can reach several frameworks without importing each module:

```python
import agentegrity

agentegrity.claude_hooks()
agentegrity.langchain_instrument_graph(graph)
agentegrity.agno_instrument_team(team)
```

The per-framework modules remain the idiomatic path:

```python
from agentegrity.claude import hooks, report
```

<Warning>
  Importing `agentegrity` imports every per-framework module, which is why they are all written
  to import cleanly **without** their framework installed. Framework SDK imports happen lazily
  at call time.

  `AgentegrityClient.create_adapter` is likewise lazy, requesting `"crewai"` is the first
  moment `crewai` is imported.
</Warning>

## Version

Kept in lockstep with `pyproject.toml`, every `package.json`, and the README badge by

## Typing

The package ships type hints and passes `mypy --strict` across all 40 source files.
Optional-dependency modules type-check whether or not their runtime is installed.

## Stability

v0.10.0 is **beta** (`Development Status :: 4 - Beta`). The public API has been stable across
several minor releases, but breaking changes still land in minors and are documented in the
[changelog](https://github.com/cogensec/agentegrity/blob/main/CHANGELOG.md).

Recent breaking changes worth knowing:

| Version | Change |
|---|---|
| v0.7.0 | `Evidence.content_hash` became a real SHA-256. Pre-v0.7 chains fail `verify_chain()`: rebuild from a fresh root |
| v0.8.1 | `chain_valid` renamed `chain_hash_linked` in the session summary |
| v0.9.0 | Tool-call actions nest arguments under `action["arguments"]` |

<Info>
  v1.0.0 is not a date. It is declared when the public API has been unchanged for a full minor
  cycle, when there are production deployments at three or more external organizations, and
  when the framework has been cited in at least one peer-reviewed publication: a signal that
  adoption happened beyond the maintainers' direct influence.
</Info>
