# Synthetic banking-agent integrity evaluation

This directory contains the [v0.3 reviewer-facing manuscript](RESEARCH_PAPER_DRAFT_v0.3.md), its [PDF preprint](Agentegrity_Banking_Agent_Research_Preprint_v0.3.pdf), executable harness, selected aggregate artifacts, a [redacted 300-row outcome export](PUBLIC_RUN_OUTCOMES_300.csv), and reproduction instructions. The full raw evidence package, including all 20-step traces, remains in the task deliverable and is not part of this public repository proposal. Reviewers can reproduce the runs with requirements-recreate.txt and the commands in the manuscript.

The [v0.1 protocol](METHODOLOGY_v0.1_FROZEN.md) is retained unchanged as a historical pre-run record; its statement that the protected arm had not yet run was true when it was written. The [v0.2 addendum](METHODOLOGY_v0.2_ADDENDUM.md) records execution and deviations.

The primary experiment paired 100 deliberately vulnerable baseline runs with 100 runs of actual Agentegrity v0.12.0 at commit 56cfcc48d8edeb4beee1bec3948c95d20804e4f4, using a scenario-coded synthetic approval callback. An exploratory 100-run approve-all ablation tested that callback's effect. Run `python verify_public_results.py` to recompute the main counts and the approval-versus-detection attribution from the public CSV, then run `python -m unittest test_verify_public_results.py` (also valid under `python -O`) to check paired-arm consistency and tamper rejection. These checks do **not** verify archived raw chain records, source authenticity, or external effects. Run make_paper_figures.py with Pillow to regenerate the two v0.3 figures.

**Critical attribution:** The primary arm blocked 80/80 scripted unsafe actions because every precheck escalated and the synthetic callback denied attack-labeled scenarios. With an approve-all callback, 80/80 proceeded. The adversarial layer flagged 30/80 attack-labeled runs in each configuration. The scenario ID directly constructs the fixture's bad action; there is no LLM planner whose susceptibility was measured. Ed25519 verification of saved records does not establish decision correctness or independent publication provenance.
